NEO GOT MY RATE
Acerca del proyecto

Plataforma web inspirada en el modelo de Letterboxd diseñada para catalogar, calificar y reseñar la discografía del colectivo NCT y sus subunidades (NCT 127, DREAM, WayV, Wish y proyectos solistas). Implementa una arquitectura full stack con backend en Go y base de datos relacional SQLite para la gestión de usuarios, álbumes y reseñas, combinada con una interfaz web responsiva orientada al descubrimiento musical.

Puntos técnicos clave
  • Modelo relacional normalizado en SQLite para artistas, lanzamientos discográficos y reseñas de usuarios.
  • Handlers de servidor en Go para el enrutamiento dinámico y persistencia de datos.
  • Interfaz responsiva con componentes interactivos y navegación optimizada para catálogos musicales extensos.
